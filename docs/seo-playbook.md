# SEO Playbook

## Every Page
- Unique title
- Meta description
- Canonical URL
- H1
- Logical headings
- Internal links
- Optimized images
- Alt text

## Content
- Solve one search intent per page.
- Use clear Bahasa Indonesia.
- Build topical authority.
- Include FAQ where relevant.

## Performance
- Optimize Core Web Vitals.
- Compress images.
- Lazy load where appropriate.
- Minimize JavaScript.

## Technical SEO
- Sitemap
- robots.txt
- Structured data
- Open Graph
- Twitter Cards
