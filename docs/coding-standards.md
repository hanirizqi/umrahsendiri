# Coding Standards

## Stack
- Nuxt 3
- Vue 3 Composition API
- Tailwind CSS
- TypeScript

## Rules
- Small reusable components.
- Shared logic in composables.
- Keep business logic out of UI.
- Meaningful naming.
- Avoid duplicated code.
- Prefer server routes for backend work.

## Styling
- Tailwind utilities first.
- Consistent spacing.
- Accessible colors.
- Responsive by default.

## Quality Checklist
- Readable
- Typed
- Tested manually
- SEO unaffected
- Performance considered
